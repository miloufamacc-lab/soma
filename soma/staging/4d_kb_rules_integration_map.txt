  - Read: RULE-0401 (position sizing tiers)
  - Use: validate_trade_write() calls validator against Tier-3 limits
  - Action: Block trades that violate tier allocation rules

ORACLE (Collection):
  - Read: RULE-0402 (change detection criteria)
  - Use: DELTA, SENTINEL pipelines output to staging/prism files
  - Action: Flag observation_date for each change signal (repricing window calculation)

SOMA (Synthesis):
  - Read: RULE-0402, RULE-0403 (pattern recognition)
  - Use: Aggregate multi-domain change signals, calculate information lag
  - Action: Write to brief_log with confidence + lag estimates

CIPHER (Communication):
  - Read: RULE-0403 (moat durability), RULE-0404 (impact ROI)
  - Use: Risk assessment for pattern publication, impact reporting
  - Action: Flag client communications for pre-publication moat review

RAPTOR (Acquisition):
  - Read: RULE-0401 (capital bucketing), RULE-0404 (impact ROI)
  - Use: Client segmentation + impact advisory positioning
  - Action: Pre-compute target allocations by client profile
